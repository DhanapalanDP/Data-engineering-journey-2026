📦 Variables & Data Types
1. Variables (The Pointers)
A variable is a named pointer that holds a piece of data in the computer's memory.

You create one by assigning a value using the = sign.

Python uses Dynamic Typing: You don't have to declare the type upfront.

Example: record_id = 101

2. The 4 Core Data Types

Integer (int): Whole numbers. Used for counting items (e.g., row_count = 500).

Float (float): Decimal numbers. Used for precise measurements or currency (e.g., temperature = 98.6).

String (str): Text data. Must always be wrapped in quotation marks (e.g., status = "active").

Boolean (bool): Logical switches that are only ever True or False (e.g., is_clean = True).

3. Type Casting (Data Conversion)

The process of changing data from one type to another.

When extracting raw data from APIs or CSVs, numbers often arrive as Strings. You must "cast" them before doing math.

Example: clean_price = float("45.99")

Pro-tip: If you are ever confused by a variable, print type(variable_name) to see exactly what it is.
🚂 Python Lists (The Cargo Train)
1. What is a List?

A List is a single variable that can hold multiple pieces of data at the same time in a specific order.

Think of it as a long train: one train, but many individual cargo cars.

You build them using square brackets [] and separate each item with a comma.

Example: my_favorite_foods = ["Pizza", "Dosa", "Ice Cream"]

2. The Zero-Indexing Rule

To pull a specific item out of the list, you have to tell Python exactly which "car" to look inside.

Important: Computers always start counting at 0, not 1!

The first item is [0], the second item is [1], the third is [2].

Example: print(my_favorite_foods[1]) will print "Dosa".

Assuming we start with a basic list: data = [10, 20, 30]

Create: data = [10, 20, 30] (Builds a list of multiple items inside square brackets).

Access: data[0] (Extracts the 1st item using zero-indexing: 10).

Last Item: data[-1] (Extracts the very last item using negative counting: 30).

Modify: data[1] = 25 (Changes the 2nd item; the list is now [10, 25, 30]).

Add (Append): data.append(40) (Sticks a new item on the end: [10, 25, 30, 40]). we can use + as well. data = data + [40]

Count (Len): len(data) (Returns the total number of items inside the list: 4).

Slice: data[0:2] (Grabs a chunk from index 0 up to 2: [10, 25]). [start : end] start is inclusive and end is exclusive.

Delete by Value: data.remove(25) (Finds the exact value 25 and deletes it).

Delete by Index: del data[0] (Deletes whatever item is sitting in the 0 slot).

Sort: data.sort() (Permanently organizes the list from smallest to largest).

Merge: [1, 2] + [3, 4] (Glues two lists together into one: [1, 2, 3, 4]).

Sublist (2D): table = [[1, 2], [3, 4]] (Creates a nested list, representing rows and columns).
Read Sublist: table[1][0] (Grabs the 2nd row [1], then grabs its 1st item [0]: 3).

🐍 Python Learning Notes: Functions, Methods, and Packages
1. Functions (Building Magic Machines)
Functions let you write a chunk of code once and use it over and over again without re-typing it.

Defining a function: Use the def keyword to build the machine.

Inputs/Arguments: The ingredients you pass into the function inside the parentheses ().

Return: The return keyword gives the final result back to you.

Python
def make_juice(fruit):
    yummy_drink = fruit + " juice"
    return yummy_drink

# Calling the function to use it!
my_cup = make_juice("Apple") 
2. Built-in Functions (Free Tools)
Python comes with a toolbox of pre-built functions you can use instantly.

print(): Shouts text onto the screen.

len(): Tells you the length (number of items) of a word or list.

max() / min(): Finds the highest or lowest number in a group.

input(): Asks the user a question and waits for them to type an answer.

sorted(): Sorts a list in alphabetical or numerical order.

Note: It creates a copy and doesn't destroy the original list.

Power-up: Use sorted(list, reverse=True) to sort backward!

3. Getting Help & Exploring
If you ever forget how a tool works, Python has built-in librarians.

help(): Pass a tool into it (like help(len)) to read the instruction manual.

dir(): Acts like X-ray glasses. Pass an object into it (like a string or list) to see a giant list of all the hidden tools (methods) it has.

4. Objects and Methods
In Python, everything is an object, and objects have specific methods associated with them depending on their type. A method is a special trick that belongs only to a specific type of object. You use a dot (.) to call it.

String Methods: A string object like sister has a .replace() method. Example: sister.replace("z", "sa"). Another example is .upper() to make words uppercase.

List Methods: A list like fam does not have a .replace() method, and trying to use it will give an AttributeError. However, lists have their own tricks, like .append(), which adds a new item to the very end of the list.

5. Packages (Expansion Packs)
Functions and methods are powerful, but Python doesn't include all code in its main distribution. If it did, the code base would be huge and messy, it would include lots of code you won't ever use, and it would cause a maintenance problem. Instead, extra tools are kept in packages.

Installing Packages using pip
Before importing a third-party package, you must install it using the terminal:

Go to https://pip.pypa.io/en/stable/installation/.

Download the get-pip.py file.

Open your terminal and run: python3 get-pip.py to set up pip.

Install your package: pip3 install numpy.

Ways to Import Packages
Bring the whole box: import math (Must use the dot: math.sqrt())

Grab just one tool: from math import sqrt (Use directly: sqrt())

The Nickname Trick: import numpy as np (Use the short name: np.array())

6. Python Lists vs. Arrays (NumPy)
Both hold items in a row, but they act differently:

Python Lists ([]): Like a magic backpack. They can mix different data types together (words, numbers, booleans) but are slower for heavy math.

Arrays (using NumPy): Like a strict collector's case. They only hold one type of data (usually numbers) but are lightning-fast and take up less memory.

NumPy (Numeric Python) Basics
What it is: A foundational Python package for fast, efficient numerical computations.

NumPy Arrays vs. Python Lists: * Arrays must contain only one single data type (e.g., all floats or all integers).

They are significantly faster and more memory-efficient than lists because they are stored contiguously in memory (written in C).

Vectorization: You can perform element-wise mathematical operations on entire arrays at once without writing slow for loops (e.g., array1 + array2).

Array Creation & Manipulation
Creating an array: np.array([1, 2, 3])

Generating random data: np.random.normal(mean, standard_deviation, size) creates an array of a specific size following a bell-curve distribution.

Combining arrays: np.column_stack((array1, array2)) merges 1D arrays into a 2D matrix. Crucial rule: The input arrays must have the exact same number of elements.

Subsetting (Extracting Data)
Works exactly like standard Python list slicing using square brackets []:

my_array[0]: Grabs the first element.

my_array[-1]: Grabs the last element.

my_array[1:4]: Grabs a slice of elements (from index 1 up to, but not including, index 4).

Core Statistical Functions
np.mean(): Calculates the arithmetic average. Warning: Highly sensitive to extreme outliers.

np.median(): Finds the exact middle value of sorted data. Best choice when your dataset has extreme outliers.

np.std(): Calculates the Standard Deviation. Measures how spread out the data is from the mean (low = tight cluster, high = wide spread).

np.corrcoef(): Calculates the Correlation between two sets of data. Returns a matrix showing relationships from -1.0 (perfect negative) to 1.0 (perfect positive).

np_height1 = np.round(np.random.normal(1.75, 0.20, 5000), 2)
np_weight1 = np.round(np.random.normal(60.32, 15.00, 5000), 2)

np_city = np.column_stack((np_height1, np_weight1))
print(np_city)
Example:
np_mean = np.mean(np_city[:, 0])
np_median = np.median(np_city[:, 0])
np_standard_dev = np.std(np_city[:, 0])
np_correlation = np.corrcoef(np_city[:, 0], np_city[:, 1])
print(np_mean)  
print(np_median)
print(np_standard_dev)
print(np_correlation)
